# Java Expense Tracker

## Project Overview

The Java Expense Tracker is a simple application designed to help college students manage their spending. Many college students, myself included, struggle to manage their spending because small purchases can quickly add up without them noticing.

The goal of this project is to allow users to record and categorize their purchases, monitor their spending, and compare their expenses against a monthly budget.

## Features

The application will allow users to:

- Add expenses with a name, category, amount, and date.
- View and organize recorded expenses.
- Calculate total spending.
- Set a monthly budget and track remaining money.(If time)
- Edit and delete existing expenses.
- Save and load expense records using files.

## Technologies Used

- **Java:** Main programming language used to develop the application.
- **ArrayList in Java:** Stores and manages expense records.
- **Java File I/O:** Saves and loads expense data between sessions.
- **Java Scanner:** Handles user input through the console.
- **Java LocalDate:** Records and manages the dates of expenses.
- **Java Exception Handling:** Handles invalid inputs and file errors.
- **Git and GitHub:** Used for version control and tracking project development.
- **VS Code:** Main development environment for writing and testing the application.

## Minimum Viable Product (MVP)

The first version of the application will focus on four main features:

1. Adding and recording expenses.
2. Viewing recorded expenses.
3. Calculating total spending.
4. Saving and loading expenses using files.

These features will allow users to track their spending without needing more advanced functionality.

## Future Features

After completing the MVP, I plan to add:

- Monthly budget tracking.
- Filtering expenses by category.
- Editing and deleting expenses.
- Spending summaries and charts.

## Development Milestones

Each milestone will correspond to a Git commit.

1. Set up the project with initial Java files.
2. Create the Expense class to store expense information.
3. Add functionality for recording expenses.
4. Implement viewing and organizing expenses.
5. Calculate spending totals.
6. Implement monthly budgeting.
7. Add functionality for editing and deleting expenses.
8. Implement file saving and loading.
9. Test the application, handle errors, and finalize documentation.

## Project Structure

The planned project will contain:

- `Main.java` — Handles the console menu and user input.
- `Expense.java` — Stores individual expense information.
- `ExpenseTracker.java` — Manages expense records, calculations, and file operations.
- `expenses.csv` — Stores saved expense records.

## How to Run

The application will be developed using Java and VS Code. Once the implementation is complete, users will be able to compile and run the Java files through the terminal.
